Hark lance Handoff, un agent IA pour automatiser tes tâches sur ordinateur

Un nouvel agent IA promet de naviguer sur le web à ta place pour des tâches concrètes.

Ce qui s'est passe 🔍

Hark, la startup secrète de Brett Adcock, dévoile Handoff. C'est un "agent d'utilisation d'ordinateur" (CUA). Il est conçu pour interagir avec le web. Il peut par exemple commander un repas ou réserver un voyage. La promesse est de le faire à la place de l'utilisateur.

Hark affirme que Handoff est parmi les meilleurs agents du marché pour naviguer sur le web ouvert.

L'objectif est de rendre l'automatisation web plus accessible. Hark vise un prix abordable pour son produit.

Pourquoi ca compte 🎯

Les agents IA capables d'agir sur le web sont de plus en plus nombreux. Handoff se positionne sur la vitesse et le coût. Ces deux facteurs sont souvent des freins à l'adoption pour les outils actuels. Si Hark tient ses promesses, cela pourrait démocratiser l'usage de ces agents.
